## Features

- Sun + 8 planets + Moon (Moon orbits Earth)
- Relative orbital speeds + Play / Pause / Speed / Reset
- Click a body → info panel + Focus camera
- Toggle Orbits & Labels
- Learn mode
- Glass UI, mobile + desktop, OrbitControls

Open `index.html` in any modern browser. No build step.
